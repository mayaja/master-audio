Mastering Audio - Help & Manual

A complete guide to the features, recommended workflow, and how to reach a master that matches the target platform.

Version: Platform-aware Presets + Auto Adapt

1. Quick Workflow (Recommended)

  1. Load an audio file using the Load Audio button.
  2. Select the target platform (Spotify, YouTube, Apple Music).
  3. Choose the genre preset that best matches the song.
  4. Click Apply Target.
  5. Run Auto Adapt (Quick or Full Track).
  6. Check the Validation Report until most items show PASS.
  7. Compare Original vs Processed mode (A/B).
  8. Export WAV and Export Report.

2. When to Choose Quick vs Full

  • Quick: faster, useful for drafts and early exploration.
  • Full Track: more accurate, useful before final export.
  • If the song has major arrangement changes between sections, use Full Track.

3. Main Control Functions

  • Input / Output: adjust the starting and ending gain of the mastering chain.
  • Tone Low Mid High: global tonal shaping before detailed EQ work.
  • Compressor: controls density, punch, and dynamics.
  • Limiter: controls final loudness and true peak safety.
  • Band Solo + Solo Sweep: isolate and identify problematic frequency areas.

4. Target Validation (Practical)

  • Integrated Loudness: keep it within the target profile zone.
  • True Peak: keep it safe from inter-sample clipping.
  • Crest Factor: avoid over-compression so dynamics stay alive.
  • Stereo Correlation: make sure it stays compatible during mono playback.

Ideal status: mostly PASS, a few WARN items can still be acceptable, but avoid FAIL on true peak and integrated loudness.

5. Quick Troubleshooting

  • Integrated often shows WARN/FAIL: lower limiter Drive, lower Output, or choose Safe mode.
  • True Peak FAIL: lower limiter Ceiling and Drive.
  • Crest Factor WARN/FAIL: relax the compressor (lower ratio, slower attack) and reduce limiter drive.
  • Sound is too sharp: lower High, then check the presence band with Solo Sweep.
  • Low-end is boomy: reduce Low or cut the lower band via EQ/sweep target band.

6. Recommended Final Workflow

  1. Set the target platform and preset.
  2. Apply Target.
  3. Auto Adapt Full Track.
  4. Make small manual fine-tuning moves (max 2 to 4 parameters).
  5. Check the Validation Report again.
  6. A/B against Original at the same listening level.
  7. Export WAV + Export Report for documentation.

Note: all processing runs locally in the browser. For the most consistent results, use moderate monitoring levels and a similar reference track.
